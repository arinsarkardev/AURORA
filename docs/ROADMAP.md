# AURORA 4-Year Build Roadmap

## Phase 1 — Foundations
- Python, C++, Git, Linux
- DSA, linear algebra, calculus, probability
- Symbolic/numerical math engine
- Experiment and memory primitives

## Phase 2 — Autonomous experimentation
- Scientific simulation framework
- Parameter search and optimization
- Failure classification
- Persistent experiment lineage
- Distributed experiment execution

## Phase 3 — AI research agent
- LLM orchestration
- Tool calling
- Retrieval and scientific knowledge
- Hypothesis generation
- Evidence-based evaluation
- Uncertainty and verification

## Phase 4 — Engineering system
- Physics/domain simulators
- CAD/design interfaces
- Multi-objective optimization
- Hardware/sensor interfaces
- Real-world closed-loop experiments
- Reproducibility and research reports

## Data and security
AURORA may later connect to cameras, satellites, sensors, computers, and servers only through explicit authorization, credentials, and auditable interfaces. Security research should be performed against systems the operator owns or is authorized to test.
